# @tapt/sdk

The tracking SDK for [tapt](https://tapt.so).

tapt builds and serves pages, forms, calendars and video from one place, with every action tracked live. This package is how a funnel built outside tapt gets its events in: an npm package for codebases, with a script snippet and a server-side events API alongside it.

Not live yet. `npx @tapt/sdk` runs today and tells you as much.

```sh
npx @tapt/sdk
```

Docs will live at [tapt.so/docs](https://tapt.so/docs).
